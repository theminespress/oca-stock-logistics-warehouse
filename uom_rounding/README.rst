Give a unit of measure its own rounding precision again, for example to
always consume, pick and move **whole** sheets, boxes or pieces.

Up to Odoo 18, every unit of measure had a *Rounding Precision*. Odoo 19
removed it: all units now share the decimal precision named *Product
Unit* (Settings > Technical > Decimal Accuracy). With that precision at
2 or more decimals, a bill of materials that uses 0.04 sheet per card
asks for **20.4 sheets** to make 510 cards, and the *Pick Components*
transfer asks for 20.4 sheets too. In Odoo 18, with the Sheet unit
rounded to 1, it asked for **21**.

This module adds an optional **Rounding Precision** to each unit of
measure:

-  **Empty** (the default): the unit behaves exactly as in standard Odoo
   19. Installing the module changes nothing until you set a value.
-  **Set**, e.g. to ``1``: the unit gets Odoo 18's rounding back.
   Manufacturing orders round their components **up** to it, so the
   example above asks for 21 sheets on the manufacturing order and on
   its *Pick Components* transfer.

A setting, **Apply unit rounding everywhere**, decides how far the
unit's precision reaches. Whichever you choose, it only affects units
that have a precision.

Configuration
=============

**1. Show units of measure**

Go to **Inventory > Configuration > Settings** and, under *Products*,
enable **Units of Measure & Packagings**. Click **Save**.

The module's setting, **Apply unit rounding everywhere**, appears below
it. Leave it unchecked for now (see step 4).

|Inventory settings|

**2. Clean up fractional quantities first**

Once a unit has a precision of ``1``, Odoo refuses to validate a
quantity that isn't a whole number in that unit (*"The quantity done ...
doesn't respect the rounding precision defined on the unit of
measure"*), as Odoo 18 did. That includes the inventory adjustment that
would remove leftover fractions. So, before setting the precision on a
unit:

-  Find stock with fractional quantities in that unit (**Inventory >
   Reporting > Stock**, grouped by product) and correct it with an
   inventory adjustment, e.g. 20.4 sheets to 20 or 21.
-  Open transfers and manufacturing orders that already have fractional
   quantities keep them. When they are validated, Odoo asks for a whole
   quantity: enter the quantity actually picked or used (e.g. 21). Or
   update them beforehand.

Found more later? Clear the unit's precision, apply the adjustment, then
set the precision again.

**3. Set a unit's rounding precision**

Go to **Inventory > Configuration > Units & Packagings**. The **Rounding
Precision** column shows the units that have one; a blank cell means the
unit uses the *Product Unit* decimal precision, as in standard Odoo.

|Units of measure list|

Open the unit, e.g. *Sheet*, and enter its **Rounding Precision**:

-  ``1``: whole units only (sheets, pieces, boxes).
-  ``0.5``: halves; ``0.01``: hundredths.
-  Empty or ``0``: no precision of its own (standard Odoo).

The value must be a multiple of the *Product Unit* decimal precision
(``0.01`` with 2 decimals, ``0.000001`` with 6), because quantities are
not stored with more decimals than that.

|A unit rounded to whole units|

A unit without its own precision says so:

|A unit without its own precision|

The value takes effect immediately for every quantity Odoo computes from
then on.

**4. Choose how far the precision reaches (optional)**

In **Inventory > Configuration > Settings**, **Apply unit rounding
everywhere**:

-  **Off** (recommended): Odoo rounds the quantities it computes in the
   unit (see the table in the description), but converts and compares
   quantities with the *Product Unit* precision, as in standard Odoo 19.
-  **On**: the unit's precision is also used to convert quantities
   between units and to compare them, as in Odoo 18 and earlier. For
   example, converting 0.25 *Box of 10* into a unit rounded to ``1``
   gives 3 instead of 2.5, and 0.4 of a unit rounded to ``1`` counts as
   zero, so leftover fractional stock (step 2) is ignored instead of
   shown.

Usage
=====

Example: business cards printed 25 per sheet, so the bill of materials
of one card uses 0.04 *Sheet* of paper.

**Without a rounding precision on Sheet** (standard Odoo 19), a
manufacturing order for 510 cards needs 20.4 sheets:

|Manufacturing order needing 20.4 sheets|

and, with *Pick components then manufacture* in the warehouse, the *Pick
Components* transfer moves 20.4 sheets:

|Pick Components transfer for 20.4 sheets|

**With Sheet rounded to 1**, the same order needs 21 sheets, rounded up
because a partial sheet still has to be picked and used:

|Manufacturing order needing 21 sheets|

|Pick Components transfer for 21 sheets|

Nothing else changes in the way you work: create and process
manufacturing orders, transfers and sales as usual.

Tip: a bill of materials whose quantity is a rounded fraction (e.g.
0.866667 for 13/15) can exceed a whole number by a tiny amount (120 x
0.866667 = 104.00004), which rounds up to one more unit (105). Express
such a bill of materials for a larger quantity instead (13 sheets for 15
units), so the quantity is exact.

Known issues / Roadmap
======================

-  With **Apply unit rounding everywhere** off, a few places in Odoo
   still read a unit's ``rounding`` field directly instead of calling
   ``uom.uom.compare()`` / ``is_zero()``; they keep using the *Product
   Unit* precision, as intended.
-  Odoo 20 removes the ``rounding`` field from ``uom.uom`` and converts
   quantities with the *Product Unit* precision directly: the 20.0
   version has to restore the field and override ``_compute_quantity()``
   as well.
